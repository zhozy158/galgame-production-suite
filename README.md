# 《夏日心跳方程式》与 Galgame 制作套件

本仓库首先是一部已经可以完整游玩的原创中文 Galgame——《夏日心跳方程式》；同时也包含支撑它运行、并可继续制作下一部作品的模块化浏览器 Galgame 框架。

![《夏日心跳方程式》封面](games/summer-heart-equation/assets/cg-v2/cover.png)

## 已完成作品：《夏日心跳方程式》

盛夏，陆遥回到阔别七年的海边小镇星汐町。一段本不该在此刻出现的录音，把他引向废弃的海岸电台，也重新连接起三名曾被时间推向不同方向的少女。

林夏、唐桃与沈月正在尝试修复那座电台。随着旧母带、未完成的试播记录和暴雨中的异常信号相继出现，四个人逐渐发现：这座电台似乎能够把“未来的声音”送往过去。那些当年没能说出口的话，还有机会抵达正确的人吗？

这是一段围绕重逢、记忆、选择与未完成告白展开的海边青春故事。共通线会经历车站重逢、旧电台修复、灯塔资料室调查、夏祭与暴雨广播，最终根据玩家的选择进入三条角色路线。

### 三位女主角

- **林夏**：安静、理性而克制的技术型少女。习惯用参数和误差解释世界，却始终不知道该怎样校准自己的心意。她的路线结局是“星光抵达以前”。
- **唐桃**：明快、行动力十足的青梅竹马。总能用玩笑和汽水把沉重气氛打散，却把最认真的那句话藏了整整七年。她的路线结局是“桃子汽水不会过期”。
- **沈月**：沉静细腻的资料馆员，擅长保存别人遗落的文字与声音。她比任何人都明白记录的意义，也最害怕替一段关系写下结尾。她的路线结局是“写给明天的空白页”。

### 游戏内容

- 约 30 分钟单路线体验
- 12 个可达场景、291 个文本节点
- 三条女主路线与三个完整结局
- 27 种选择组合均可抵达合法结局
- 7 张场景背景、7 张事件 CG 与独立封面
- 三名女主各有标准立绘、5 种表情和剧情动作立绘
- 131 句女主日语配音，屏幕文本保持中文
- 自动播放、已读快进、履历、隐藏界面与语音重播
- 自动存档、快速存读、8 个手动存档位及存档导入/导出
- 8 项回忆相册、事件 CG 自动解锁与结局记录
- 桌面和移动端响应式界面

人物采用当代日本动画与视觉小说式平涂风格，以角色身份母版锁定脸型、刘海分组、瞳色、发饰、服装叠穿和身体比例。正式运行立绘位于 `games/summer-heart-equation/assets/characters-v2/`，绘图提示词、候选关系和验收记录也随仓库完整保留。

### 如何游玩

下载或克隆本仓库后，在仓库根目录运行：

```powershell
npm start
```

然后打开：

- 作品库：<http://127.0.0.1:4173/>
- 直接进入游戏：<http://127.0.0.1:4173/games/summer-heart-equation/>

游戏是零依赖的静态网页，也可以直接打开 `games/summer-heart-equation/index.html`。存档保存在浏览器 `localStorage` 中。

键盘操作：`Space` / `Enter` 推进，`A` 切换自动播放，`Ctrl` 切换快进，`Esc` 返回。

### 作品文件

```text
games/summer-heart-equation/
├─ game/config.js       # 角色、背景、CG、相册和结局配置
├─ game/story.js        # 完整剧情、选择和路线
├─ game/voice-map.js    # 剧情节点到日语语音的映射
├─ assets/              # 正式立绘、背景、CG、配音和候选资产
├─ art/                 # 绘图提示词、语音台本与生成记录
├─ docs/                # 角色圣经与美术生产计划
├─ theme.css            # 本作视觉主题
└─ index.html           # 游戏入口
```

更详细的作品说明见 [《夏日心跳方程式》README](games/summer-heart-equation/README.md)。

## 可复用 Galgame 制作套件

仓库的另一部分是一套面向多作品的公共制作框架。目标是让公共能力只实现一次，而每部 Galgame 的剧情、配置、美术、音频和生成记录保持独立。新增游戏依赖公共框架，公共框架不会反向引用任何单部作品。

### 目录职责

```text
galgame/
├─ framework/                 # 跨作品公共引擎与默认界面
│  ├─ engine/vn-engine.js
│  └─ styles/vn-core.css
├─ games/                     # 每部游戏一个独立目录
│  ├─ catalog.json            # 作品库目录
│  └─ summer-heart-equation/  # 当前完成作品
├─ templates/game-starter/    # 新作脚手架
├─ art-direction/             # 全局画风、参考图与身份母版制度
├─ tools/                     # 新建项目、语音生产和自动校验工具
├─ docs/                      # 跨作品标准生产流程
└─ index.html                 # 作品库启动页
```

### 公共框架能力

- 场景、旁白、对话、角色在场状态与说话人高亮
- 图片背景、表情/动作差分与可持久化事件 CG
- 选择、状态写入、条件判断、条件选项和场景跳转
- 存档、自动播放、快进、履历、设置、相册与结局记录
- 可选逐句语音映射、切句停止、重播、音量和自动等待
- 作品级主题覆盖以及桌面/移动端响应式布局

作品与框架保持单向依赖：

```text
games/<game-id> ──依赖──> framework
```

不同作品通过 `game/config.js`、`game/story.js`、`theme.css` 和自己的 `assets/` 表达差异，不需要向公共引擎添加按游戏 ID 判断的特例。因此修改剧情走向、增加分支或新增作品，都不必复制整套框架。

### 创建下一部游戏

```powershell
npm run new-game -- moonlit-letter "月下书简"
```

命令会从模板创建 `games/moonlit-letter/`，替换作品标题和项目 ID，并自动加入作品目录，不会复制或修改《夏日心跳方程式》。

### 自动校验

```powershell
npm test
npm run validate-game -- games/summer-heart-equation
```

校验器会检查 JavaScript 语法、素材引用、角色和背景、跳转目标、不可达场景、死路、循环、结局以及全部选择组合，并输出单次路线字数和体验时长估算。
