# 《夏日心跳方程式》V2 美术生产计划

## 制作原则

- 三位女主只使用已批准的 V2 身份母版，禁止凭文字重新设计。
- 角色一致性优先级高于单张画面的华丽程度；脸型、刘海分组、发饰、瞳色、叠穿关系和身体比例逐项验收。
- 立绘采用透明背景、固定画布和固定站位；表情差分只改变眉眼与嘴部。
- 背景不含可辨识人物，降低视觉噪声并避免无关角色反复变化。
- 事件 CG 采用第一人称或不展示男主正脸的构图，避免在未建立男主母版前引入新的身份漂移。
- 新版封面最后制作，只使用已批准角色母版和已验收的场景语言。
- 所有原始提示词、参考图角色、候选路径、批准路径和接入节点均写入 `art/asset-manifest-v2.json`。

## 生产批次

1. `BG-A`：七张无人物背景。先统一世界观、光色和线条语言。
2. `SPR-EXP`：十五张表情差分。逐角色完成并做身份一致性检查。
3. `SPR-ACT`：三张动作立绘。只做剧情高频且能明显增加画面变化的姿态。
4. `CG-MAIN`：四张共通线事件 CG。
5. `CG-END`：三张个人结局 CG。
6. `COVER`：三女主新版封面。
7. `INTEGRATION`：配置、剧情表情标注、相册解锁、全路线及视觉回归。（已完成）

## 验收门槛

- 角色：逐项符合 `CHARACTER_ART_BIBLE.md`，且没有油亮皮肤、厚涂、3D 感或欧美式写实体块。
- 透明立绘：1024×1536、PNG、实际 Alpha 透明、脚底/裙摆无裁切。
- 背景/CG：16:9，推荐 1536×1024 或更高；文本框覆盖区不得放关键叙事信息。
- 游戏：所有引用存在，旧存档有回退，三条路线可达结局，移动端不溢出。
